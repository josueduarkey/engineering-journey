## El problema

Las experiencias intensivas de aprendizaje como Key Week generan trabajo, reflexiones, evidencia y colaboración durante días enteros. Pero al finalizar, todo queda disperso: fotos sin contexto, documentos sin conexión, recuerdos sin estructura.

Sin un sistema de archivo, esas experiencias pierden su valor educativo con el tiempo. El conocimiento no se acumula — se olvida.

## El proceso

- Identificar qué información es crítica preservar de cada experiencia PBL: reto, equipo, proceso, resultados y reflexión
- Analizar cómo relacionar Key Weeks con proyectos, artículos y competencias del modelo educativo
- Diseñar una estructura de contenido que pueda crecer sin depender de una base de datos
- Explorar cómo vincular el archivo histórico con el timeline de trayectoria personal

## Resultados

- Modelo inicial de contenido para futuras entradas de Key Week dentro de la plataforma
- Definición de los campos clave que debe tener cada entrada de experiencia PBL
- Relaciones iniciales entre el archivo histórico, proyectos y reflexiones personales

## Lecciones aprendidas

- El contexto es lo que convierte la evidencia en aprendizaje — sin contexto, una foto es solo una foto
- Los aprendizajes colaborativos necesitan registrar roles, decisiones y resultados, no solo el producto final
- Diseñar para el futuro significa aceptar que el contenido completo llegará después — pero la estructura debe estar lista
